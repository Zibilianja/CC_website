# Creative Corvid — Portfolio Site

A fast, accessible portfolio site for Creative Corvid. Built with **Vue 3 + Vite** and deployed on **AWS Amplify**. Includes dark/light theming and a reusable component library.

## Tech Stack

- **Frontend:** Vue 3, Vite, (optional) TypeScript, Pinia
- **Styles:** SCSS/PostCSS, CSS variables for theming
- **Hosting/CDN/HTTPS:** AWS Amplify Hosting
- **Routing:** Vue Router (history mode)
